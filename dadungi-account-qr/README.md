# 다둥이 대리 계좌QR

아이폰과 안드로이드 홈 화면에 추가해 사용하는 정적 웹앱입니다. 실행하면 사용자가 제공한 QR 이미지 원본과 ‘카카오뱅크’를 표시합니다.

배포 주소: https://cyberkjh36.github.io/dadungi-account-qr/

배포 위치: cyberkjh36/cyberkjh36.github.io 저장소의 dadungi-account-qr/ 폴더.

- 아이폰: Safari → 공유 → 홈 화면에 추가 → 추가. ‘웹 앱으로 열기’가 있으면 켭니다.
- 안드로이드: Chrome → 홈 화면에 추가 버튼 또는 ⋮ 메뉴 → 앱 설치/홈 화면에 추가.
- 최초 온라인 접속 시 앱과 QR을 저장합니다. 브라우저가 사이트 데이터를 지우면 다시 온라인으로 열어야 합니다.
- 첨부 QR이 가리키는 계좌 복사 페이지를 여는 상대방 휴대폰에는 인터넷 연결이 필요합니다.
- 앱 제목과 아이콘을 manifest와 Apple 메타데이터로 지정했습니다. 휴대폰 화면 폭에 따라 아이콘 아래 이름 일부가 줄여 보일 수 있습니다.
- QR 원본 파일은 변경하지 않았습니다. 외부 스크립트·분석·추적·별도 로그인 없이 동작합니다.

dist/의 모든 파일을 지정 폴더로 배포합니다. 기존 저장소 루트와 dadungi-copy/는 수정하지 않습니다. 앱 자산을 수정할 때 sw.js의 캐시 버전을 올립니다.
