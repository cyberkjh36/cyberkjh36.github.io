# 느티나무 방 QR 앱 연결

GitHub Pages 도메인 루트에서 Android App Links 공개 서명 정보를 제공합니다.

- 앱: `kr.neutinamu.p2.direct` (0.9.0 이상)
- 연결 파일: `https://cyberkjh36.github.io/.well-known/assetlinks.json`
- 기존 방 QR: `https://cyberkjh36.github.io/neutinamu-song-search/p2-room.html?room=N`
- Pages: `main` / root. `.nojekyll`을 유지해 `.well-known` 파일을 그대로 배포합니다.

개인 서명키·연결 기록·손님 정보는 포함하지 않습니다. 공개 인증서 지문만 있습니다. 실제 P2 연결은 앱의 Wi-Fi Direct 연결과 기기 식별 검사 후 성립합니다.
